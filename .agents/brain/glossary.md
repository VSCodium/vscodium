# Brain: Glossary

Shared terminology for Cursor ING development.

| Term | Definition |
|------|-----------|
| **Agent** | An AI-powered worker with a specific role, permissions, and tool access |
| **Agent Roster** | The team of agents available in a Cursor ING session |
| **Activity Log** | Structured audit trail of all agent actions |
| **Composer** | The AI chat/command interface (like Cursor's composer) |
| **Diff Preview** | Side-by-side or inline view of proposed changes before approval |
| **Harness** | The .agents/ directory structure containing agent definitions |
| **Mock Provider** | Deterministic AI provider that works without API keys |
| **Plan** | Structured task breakdown with steps, statuses, and approvals |
| **Provider** | An AI model backend (OpenAI, Anthropic, Ollama, etc.) |
| **Provider Registry** | Factory that creates provider instances from configuration |
| **Scaffold** | Working skeleton code that demonstrates architecture |
| **Skill** | A reusable, model-agnostic capability used by agents |
| **Vendor** | Read-only open-source reference code in .agents/vendor/ |
| **Webview** | VS Code panel rendered with HTML/CSS/JS inside the IDE |
| **VSCodium** | Open-source VS Code build without Microsoft telemetry |
| **Upstream** | The VSCodium/Microsoft VS Code source we build on top of |
